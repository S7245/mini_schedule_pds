# Batch 02 — 微信支付 Native 下单

状态：**已完成** ✅（2026-05-29）
更新时间：2026-05-28

---

## API 契约

| 方法 | 路径 | 请求字段 | 响应字段 |
|---|---|---|---|
| POST | `/api/v1/public/payment/native` | `order_id: string` | `code_url: string, expires_at: string` |
| GET | `/api/v1/public/payment/orders/:order_id` | — | `status: string, paid_at: string \| null` |

**status 枚举：** `pending_payment` / `paid` / `closed` / `failed` / `exception`

---

## 前端页面模块

| 页面/模块 | 路由 | 类型 | 触发条件 |
|---|---|---|---|
| 支付页（pending） | `/signup/payment/[order_id]` | 页面 | 进入页面时自动调用下单接口 |
| 支付成功 | 同上（状态切换） | 内嵌状态 | 轮询返回 `paid` |
| 二维码超时 | 同上（状态切换） | 内嵌状态 | `expires_at` 倒计时归零 |

**交互逻辑：**
- 进入页面 → 自动 POST `/payment/native` → 渲染二维码
- 每 3s 轮询 GET `/payment/orders/:id`，status=`paid` 切换 State 2
- `expires_at` 倒计时归零切换 State 3
- 轮询失败静默重试 3 次，3 次后显示"页面刷新提示"
