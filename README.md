# mini_schedule_pds

这个仓库用于管理课程预约项目的产品背景、需求蓝图和技术约束。

## 文档目录

- `BACKGROUND.md`：项目、后端、前端和根目录背景信息。
- `CLAUDE.md`：Agent 常驻工作指令，定义 source of truth、批次节奏和实现约束。
- `COURSE_BOOKING_BUSINESS_BLUEPRINT.md`：课程预约 SaaS 完整业务蓝图。
- `GO_BACKEND_LANGUAGE_DESIGN.md`：Golang 后端语言设计和实现约束。
- `PROGRESS.md`：实现进度账本，记录 Now / Next / Later、当前缺口和下一批任务。
- `SKILLS_INVENTORY.md`：本地可用 skills 盘点。
