## 使用约定

- `LEARNINGS.md`：会话经验、可复用模式和项目内决策沉淀。
- `ERRORS.md`：命令失败、验证失败和修正线索。
- `FEATURE_REQUESTS.md`：后续希望沉淀为项目能力或 skill 改进的请求。
